Rust-Videokurs für Anfänger

🎬 Kapitel 4: Das erste Rust-Projekt (Video-Analyse & Tonspur-Bereinigung)

In diesem Kapitel erstellen wir unser erstes Rust-Projekt mit Cargo und VS Code. Um eine optimale Videoqualität zu gewährleisten, wurde die verrauschte Original-Tonspur des Videos Video/4.mp4 komplett durch eine glasklare, präzise getimte Sprachspur (TTS mit dem Kokoro-ONNX-Modell, Sprecher "Martin") ersetzt.

Das fertige Video mit der rauschfreien Tonspur ist unter 4.mp4 gespeichert.

📊 Technische Details des Videos

  • Dateiname: Video/4.mp4 (Original) / 4.mp4 (Bereinigt mit Sprecher)
  • Auflösung: 1280x720 (720p)
  • Bildwiederholrate (FPS): 30 fps
  • Dauer: 01:43.38 (103,38 Sekunden)
  • Audio-Format (Neu): AAC Mono, 48 kHz (Rauschfrei)

🎥 Szenenübersicht und Zeitstempel

Hier ist eine detaillierte Aufschlüsselung der Ereignisse im Video und der zugehörigen Sprachsegmente:

1. Intro & Cargo-Initialisierung (00:00 - 00:16)

  • Visueller Inhalt: Das Ubuntu-Terminal ist geöffnet. Der Benutzer tippt den Befehl cargo new hallowelt ein und führt ihn aus. Cargo erstellt ein neues Verzeichnis hallowelt mit den Standard-Projektdateien.
  • Sprechertext (Start: 00:01):

    "Willkommen zu Kapitel vier. Hier erstellen wir unser erstes Rust-Projekt. Im Ubuntu-Terminal nutzen wir das Tool Cargo, den offiziellen Paketmanager. Mit dem Befehl cargo new hallowelt legen wir ein neues Verzeichnis mit allen benötigten Projektdateien an."

2. VS Code öffnen (00:16 - 00:30)

  • Visueller Inhalt: Der Benutzer wechselt mit cd hallowelt (implizit) bzw. öffnet das neu erstellte Verzeichnis direkt im Editor Visual Studio Code über den Befehl code hallowelt.
  • Sprechertext (Start: 00:16.5):

    "Um den Quellcode zu bearbeiten, öffnen wir das Verzeichnis anschließend in Visual Studio Code mit dem Befehl code hallowelt."

3. Projektstruktur erkunden (00:30 - 00:46)

  • Visueller Inhalt: Visual Studio Code öffnet sich. Der Explorer auf der linken Seite wird sichtbar. Er zeigt die Struktur des frisch generierten Rust-Projekts: Die Konfigurationsdatei Cargo.toml sowie den Quellcode-Ordner src/.
  • Sprechertext (Start: 00:30):

    "Visual Studio Code öffnet sich nun. Auf der linken Seite im Explorer sehen wir die Struktur unseres Rust-Projekts. Neben der Konfigurationsdatei Cargo.toml finden wir den Quellcode-Ordner src, in dem sich unsere Programme befinden."

4. Quellcode editieren (00:46 - 01:07)

  • Visueller Inhalt: Der Benutzer klickt auf src/main.rs. Der Editor zeigt das standardmäßig generierte Hello, world!-Programm in englischer Sprache. Der Text "Hello, world!" wird in "Hallo Welt" geändert. Die Datei wird gespeichert.
  • Sprechertext (Start: 00:46):

    "Wir öffnen die Quellcodedatei main.rs im src-Ordner. Standardmäßig hat Cargo hier bereits ein einfaches Hallo-Welt-Programm in englischer Sprache generiert. Wir ändern den Text in Hallo Welt ab, um unser Programm zu personalisieren, und speichern die Datei."

5. Kompilieren und Ausführen (01:07 - 01:22)

  • Visueller Inhalt: Der Benutzer bewegt den Cursor auf den Run-Button (den Code Lens-Link direkt über der Funktion fn main()). Ein Terminal öffnet sich am unteren Fensterrand von VS Code, und der Build-Prozess wird gestartet.
  • Sprechertext (Start: 01:07):

    "Um das Programm auszuführen, klicken wir auf die kleine Run-Schaltfläche direkt über der Hauptfunktion. Visual Studio Code öffnet daraufhin am unteren Bildschirmrand ein Terminal und startet den Compiler."

6. Outro & Ausblick auf Kapitel 5 (01:22 - 01:43.38)

  • Visueller Inhalt: Das Terminal zeigt die Ausgabe des Compilers und schließlich das Ergebnis: Hallo Welt. Die Lektion wird beendet.
  • Sprechertext (Start: 01:22):

    "Der Compiler übersetzt unseren Code in kürzester Zeit und führt das Programm aus. Im Terminal sehen wir die Ausgabe Hallo Welt. Herzlichen Glückwunsch, du hast dein erstes Rust-Programm erfolgreich gestartet! Im nächsten Kapitel beschäftigen wir uns mit Variablen."

🛠️ Wie die Tonspur bereinigt wurde

  1. Sprachspur-Generierung: Mithilfe des Python-Skripts generate_audio_ch4.py wurde über das deutsche TTS-Modell Kokoro (Stimme "Martin") ein rauschfreier, hochqualitativer Begleittext erzeugt.
  2. Timing-Synchronisation: Die einzelnen Sprachblöcke wurden präzise auf die visuellen Ereignisse im Video abgestimmt (siehe Startzeitstempel in generate_audio_ch4.py).
  3. Mischen mit dem Video: Per ffmpeg wurde die verrauschte Original-Tonspur entfernt und die neu generierte Audiodatei (audio/ch4_voiceover.wav) lippensynchron und rauschfrei mit dem Video gemountet: 
    ffmpeg -y -i Video/4.mp4 -i audio/ch4_voiceover.wav -map 0:v -map 1:a -c:v copy -c:a aac -shortest 4.mp4
