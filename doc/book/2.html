Rust-Videokurs für Anfänger

Kapitel 2: Installation & Systemkonfiguration

Um mit der Programmierung in Rust unter Ubuntu Linux zu beginnen, müssen wir unser System vorbereiten und die notwendigen Entwicklungswerkzeuge installieren. Dieses Kapitel führt dich Schritt für Schritt durch die Installation aller Voraussetzungen, der Entwicklungsumgebung (IDE) und von Rust selbst.

1. Voraussetzungen: build-essential

Bevor wir Rust installieren können, benötigt unser System grundlegende Werkzeuge zum Übersetzen und Linken von Software. Rust-Programme greifen beim Kompilieren auf Systembibliotheken und den System-Linker zu.

Was ist build-essential?

Das Paket build-essential ist ein Meta-Paket in Ubuntu, das eine Sammlung der wichtigsten Werkzeuge für die C/C++-Entwicklung enthält. Dazu gehören:

  • gcc / g++: Die GNU Compiler Collection zum Übersetzen von C- und C++-Code.
  • make: Ein Werkzeug zur Automatisierung von Kompilierungsvorgängen.
  • libc-dev: Die Standard-C-Bibliotheken, die für Systemaufrufe benötigt werden.
  • dpkg-dev: Werkzeuge zur Paketierung.

Rust benötigt den in diesem Paket enthaltenen C-Linker, um den generierten Maschinencode zu lauffähigen Binärdateien zusammenzufügen.

Installation

Öffne dein Terminal und führe die folgenden Befehle aus:

# Paketquellen aktualisieren
sudo apt update

# build-essential installieren
sudo apt install -y build-essential

2. Editor & IDE: Visual Studio Code

Als Entwicklungsumgebung verwenden wir Visual Studio Code (VS Code). Es ist ein moderner, performanter und erweiterbarer Editor von Microsoft, der sich in der Entwickler-Community großer Beliebtheit erfreut.

VS Code auf Ubuntu installieren

Unter Ubuntu lässt sich VS Code am einfachsten und sichersten als klassisches Snap-Paket über das Terminal installieren:

sudo snap install --classic code

Die Erweiterung rust-analyzer

VS Code selbst besitzt standardmäßig keine tiefe Integration für Rust. Um komfortabel arbeiten zu können, installieren wir das offizielle Rust-Plugin: rust-analyzer.

  1. Öffne VS Code.
  2. Drücke Strg + Umschalt + X, um die Extensions-Ansicht zu öffnen.
  3. Suche nach rust-analyzer (von der Rust Programming Language Organisation).
  4. Klicke auf Install.

Was bietet rust-analyzer?

  • Intelligente Codevervollständigung: Vorschläge beim Tippen.
  • Syntaxhervorhebung & Formatierung: Automatisches Formatieren nach dem Rust-Standard rustfmt.
  • Echtzeit-Diagnose: Fehler und Warnungen werden direkt beim Schreiben im Code rot unterstrichen, bevor du überhaupt kompilierst.
  • Typen-Inferenz: Anzeige von automatisch erkannten Datentypen direkt im Editor.

3. Rust-Installation via rustup

Der offizielle, empfohlene und flexibelste Weg, Rust auf Unix-ähnlichen Systemen wie Linux zu installieren, ist rustup.

Was ist rustup?

rustup is der Versionsmanager für Rust. Ähnlich wie nvm für Node.js verwaltet es verschiedene Rust-Versionen (z. B. Stable, Beta, Nightly) und sorgt dafür, dass Tools wie der Compiler (rustc) und der Paketmanager (Cargo) immer auf dem neuesten Stand sind.

Installation

Kopiere das offizielle Installationsskript in dein Terminal und führe es aus:

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

Während des Installationsprozesses wird im Terminal ein Auswahlmenü angezeigt:

1) Proceed with installation (default)
2) Customize installation
3) Cancel installation

Drücke einfach 1 und dann Enter, um die Standardinstallation fortzusetzen.

Systempfad aktualisieren

Nachdem die Installation abgeschlossen ist, müssen die Rust-Tools zu den Umgebungsvariablen deines Terminals hinzugefügt werden. Führe dazu entweder den folgenden Befehl aus oder starte dein Terminal einfach neu:

source "$HOME/.cargo/env"

Überprüfung der Installation

Um zu verifizieren, dass Rust erfolgreich installiert wurde und einsatzbereit ist, kannst du die Version des Compilers abfragen:

rustc --version

Die Ausgabe sollte der folgenden ähneln (Version und Datum können abweichen): rustc 1.80.0 (sha 2026-06-06)

Dein System ist jetzt vollständig eingerichtet und bereit für dein erstes Rust-Projekt!
