Beschreibung für Anfänger: KI-Assistenten nutzen Tools, erledigen Aufgaben und suchen im Internet nach weiteren Informationen, um zu zeigen, wie diese Tools funktionieren.
* Cline ist ein KI-Assistent, der Entwicklern hilft, Code schneller zu schreiben und zu verstehen.
* Gemini Code Assist ist ein KI-gestütztes Tool von Google, das bei der Code-Vervollständigung, Fehlererkennung und Refactoring unterstützt.
* Github Copilot ist ein KI-Paarprogrammierer, der Code basierend auf Kommentaren und umgebendem Code vorschlägt. 

Das sind meine Favoriten: GitHub Copilot und Gemini Code Assist.

Warum sollte man nicht alles von KI-Agenten erledigen lassen? Man lernt nichts dabei.
